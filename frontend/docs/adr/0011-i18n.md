# ADR 0011: English message catalog, no library yet

Status: accepted

## Context

The first launch is English only, but Nepali is likely later.

## Decision

All user-facing strings live in `src/i18n/en.ts` as a typed nested object, read with `t('path.to.key', params)`. Dates and numbers use `Intl` with an explicit locale and time zone.

## Consequences

Adding a language means adding a catalog. A library is added by ADR only if pluralization needs grow.
