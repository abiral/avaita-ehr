# Folio EHR web

Frontend for the Folio EHR: patient portal, clinician workspace and admin console, built for many hospitals.

Live design prototype: https://claude.ai/artifact/TDhAGBd5qEXTQiB6KtZa9D

- `CLAUDE.md`: instructions Claude Code reads first
- `docs/codebase.md`: architecture, rules and build phases
- `docs/HANDOFF.md`: screens, flows, design tokens, data model
- `docs/design/`: one design file per screen
- `docs/KICKOFF.md`: one prompt per build phase

Setup instructions are added in phase F0.
